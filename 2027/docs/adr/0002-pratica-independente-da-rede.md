# Separar aquisição e uso didático dos dados

As aulas e avaliações usam bases locais documentadas. A aquisição por API permanece ensinada e tem scripts próprios, mas não é executada ao renderizar os roteiros. Bloqueios de acesso, revisões dos dados e limites das APIs não devem impedir a prática ou alterar silenciosamente uma avaliação. O custo é manter e identificar cada extração; a vantagem é permitir reprodução da análise no mesmo conjunto de dados.
